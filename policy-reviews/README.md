# Executive Summery

**Introduction**

This executive summery has been produced for the review of a security policy, with any findings and problem areas highlighted.  

**Objectives** 

Review of the policy to ensure that it is up to date with changing standards and relevant to the current threat landscape.

**Key Findings**

Roles need to be defined further under scope.

Data classification is missing – Public, internal, confidential, handled per defined guidelines

Access control requires further defining and control mapping with best practices.

Incident response should be clearer.

**Recommended actions**

* Password requirements are not following the current best practices. NIST SP 800-63B prescribes log passwords or phrases, password managers, 2FA and passkey adoption  
* Further least privilege, privileged account definition.  
* Joiner/mover/leaver processes to be defined  
* Remote working – using a VPN is not currently implemented,  vague description of what is required.  
* Clear statement of use of BYOD required, personal USB devices and the use of them.  
* Incident response timeframe added for clarification

**Conclusion**

The policy needs to be brought further in-line with the ISO27001 framework to insure that it meets the required standards.  In doing so will further harden the security posture of the company.
